# Xybrid Demo

This is a small single screen app for the Xybrid SDK.

### What it does

It demonstrates initializing Xybrid and loading a speech-to-text model (`whisper-tiny-ggml`) from the registry

### Full Example App

The complete Flutter example app with 8 demo screens can be found at: https://github.com/xybrid-ai/xybrid/tree/master/examples/flutter
