@xybrid/web preview

Run a small language model in your browser

This page downloads SmolLM2-135M-Instruct, a 136 MB open language model, and generates text entirely in this tab, on your GPU when WebGPU is available. Nothing is uploaded: the prompt, the model, and every generated token stay on your device. Prefer raw tensors? Run the deterministic TFLite addition model instead.

Run it

auto runs on WebGPU and falls back to the CPU engine when the browser has no GPU support.

Sent to the model as a single user turn. Replies are capped at 256 tokens.

Result

  1. Load download the 136 MB model (the browser caches it) and start the on-device engine

  2. Generate stream the reply token by token from the on-device engine
