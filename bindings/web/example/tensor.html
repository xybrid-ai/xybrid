Run a TensorFlow Lite model in your browser

This page loads a real 708-byte .tflite model, compiles it with LiteRT, and executes it entirely in this tab. Nothing is uploaded: the model adds two 10 by 10 float32 tensors on your device, and the page verifies all 100 outputs. Looking for something chattier? Talk to a small language model instead.

Run it

auto compiles for WebGPU and falls back to wasm when the browser has no GPU support.

Input a is fixed to 0 through 99, so every output should equal its a plus your b.

Result

  1. Load fetch model_metadata.json and model.tflite, compile for the accelerator

  2. Run execute the model with a and b as float32[10, 10] inputs

  3. Verify compare every output value against a + b computed in JavaScript

READY Pick an accelerator and press run. The model executes locally in this tab.
