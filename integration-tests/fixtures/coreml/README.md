# Native Core ML fixture

`xybrid_linear.mlpackage` is a tiny deterministic linear classifier generated by
`generate_linear_classifier.py`. It accepts one Float32 `MLMultiArray` named
`input` with shape `[4]` and emits `scores` with shape `[3]`.

For `[1, 2, 3, 4]`, the expected result is `[0.25, 1.5, 8.0]`. The fixture is
generated locally, contains no third-party weights, and is covered by the
repository's Apache-2.0 license.

Regenerate it with:

```shell
python -m pip install coremltools==9.0 numpy
python integration-tests/fixtures/coreml/generate_linear_classifier.py
```
